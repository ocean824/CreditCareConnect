2️⃣ Rule logic (what I’m checking)

I’m using six core rules:

R1_FCRA_STATUS_INCONSISTENT_ACROSS_BUREAUS

Law hook: FCRA 15 U.S.C. § 1681e(b) – “maximum possible accuracy.”

Logic: For a given account (same creditor + account group), if the status / delinquency severity differs across bureaus (e.g., 120 days late vs 180 days late vs current), flag a violation for every bureau involved.

R2_FCRA_BALANCE_INCONSISTENT_ACROSS_BUREAUS

Law hook: FCRA 1681e(b).

Logic: For a given account, if the reported balance or past-due differs materially across bureaus (e.g., $0 vs $11,265), flag a violation for every bureau in that account group.

R3_METRO2_CHARGEOFF_PAST_DUE_NONZERO

Hook: Metro 2 guidance for charge-offs (past-due usually 0 once charged off).

Logic: If an account is reported as “charge-off” or “collection/chargeoff” and past_due_amount > 0, flag a violation for that bureau.

R4_METRO2_COLLECTION_REPORTED_AS_OPEN_ACCOUNT

Hook: Metro 2 distinction between “open trade line” vs “third-party collection.”

Logic: If a tradeline is clearly a debt collector / debt buyer, but the bureau codes it as an open account with lates instead of a collection, flag a violation.

R5_FCRA_DUPLICATE_COLLECTION_SAME_DEBT

Hook: FCRA 1681e(b) – misleading duplication of derogatories.

Logic: If the same debt (same collector OR same original creditor + identical balance) appears as two tradelines on the same bureau, flag this as a duplicate collection violation.

R6_FCRA_SOLD_ACCOUNT_STILL_CHARGEOFF_STATUS

Hook: FCRA 1681e(b) + Metro 2 for sold/transferred accounts.

Logic: If an original creditor tradeline shows:

balance = 0,

remark like “sold to [X] / purchased by another lender”,

but status still shows “collection/chargeoff”,
then flag as misleading.
