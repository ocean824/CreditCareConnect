1️⃣ Absolute Resolutions (Navy FCU) – TU example

We’ll model the TransUnion situation exactly like your report:

One tradeline coded like a trade/open account with serious lates (ABSOLUTE RESOLUTIONS I).

One tradeline coded as a proper collection (ABSRES INV).

That’s what triggers:

R4 – collector mis-coded as “open trade with lates”.

R5 – duplicate collection for same debt on the same bureau.

3️⃣ Wire everything into /api/issues/analyze

Now we expose one API endpoint that:

Accepts parsed tradelines for a report.

Runs all rules.

Returns:

totalsByBureau

Raw detections

Flat AiIssueExplanation[]

Per-bureau AccountLetterSection[] for easy letter generation.

3.1. Request/response types
// api/issues.types.ts
import {
  BureauId,
  RuleDetection,
  Tradeline
} from '../rules/rules.types';
import { AiIssueExplanation } from '../ai/ai.types';
import { AccountLetterSection } from '../ai.grouping';

export interface AnalyzeIssuesRequest {
  // You can also send reportId and load tradelines server-side, but this is simplest.
  tradelines: Tradeline[];
}

export interface AnalyzeIssuesResponse {
  totalsByBureau: Record<BureauId, number>;
  detections: RuleDetection[];
  explanations: AiIssueExplanation[];
  sectionsByBureau: Record<BureauId, AccountLetterSection[]>;
}

3.2. Fastify route: /api/issues/analyze
// api/issues.routes.ts
import { FastifyInstance } from 'fastify';
import { AnalyzeIssuesRequest, AnalyzeIssuesResponse } from './issues.types';
import { runAllRulesForReport } from '../rules/rules.engine';
import { detectionToAiIssueExplanation } from '../ai/ai.explanations';
import { buildLetterSectionsForBureau } from '../ai.grouping';
import { BureauId } from '../rules/rules.types';

export async function registerIssuesRoutes(fastify: FastifyInstance) {
  fastify.post<{
    Body: AnalyzeIssuesRequest;
    Reply: AnalyzeIssuesResponse;
  }>('/api/issues/analyze', async (request, reply) => {
    const { tradelines } = request.body;

    // 1) Run the rules engine
    const { totalsByBureau, detections } = runAllRulesForReport(tradelines);

    // 2) Map detections → AI explanations
    const explanations = detections.map(detection =>
      detectionToAiIssueExplanation(detection)
    );

    // 3) Build letter sections by bureau
    const bureaus: BureauId[] = ['Experian', 'Equifax', 'TransUnion'];
    const sectionsByBureau = {} as AnalyzeIssuesResponse['sectionsByBureau'];

    for (const bureau of bureaus) {
      sectionsByBureau[bureau] = buildLetterSectionsForBureau(
        bureau,
        detections
      );
    }

    const response: AnalyzeIssuesResponse = {
      totalsByBureau,
      detections,
      explanations,
      sectionsByBureau
    };

    return reply.status(200).send(response);
  });
}

3.3. Frontend usage sketch

From your React app (or your letter-generator):

async function analyzeIssues(tradelines: Tradeline[]) {
  const res = await fetch('/api/issues/analyze', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ tradelines })
  });

  if (!res.ok) throw new Error('Issue analysis failed');

  const data = (await res.json()) as AnalyzeIssuesResponse;

  // Example usages:
  // - Show summary counts on dashboard
  console.log(data.totalsByBureau);

  // - Feed explanations into UI tabs
  console.log(data.explanations);

  // - Feed sectionsByBureau['TransUnion'] into your TU dispute letter generator
  console.log(data.sectionsByBureau.TransUnion);
}
